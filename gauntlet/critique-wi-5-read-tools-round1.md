## Criteria
- CORRECTNESS: Met. `t3_list` golden is field-for-field the condensed shell: per project `id`/`title`/`path` (from T3 `workspaceRoot`); per thread `id`/`projectId`/`title`/`worktreePath`/`latestTurn` `{turnId, state}`/`hasPendingApprovals`/`hasPendingUserInput`. Mode-B relay `POST /v1/environments/:id/status` is WI-9; WI-5 liveness is the unauthenticated descriptor, including for `ctx.state` discovered rows.
- CONTRACT: Met. Handlers are `(args: dict, **kwargs) -> str`, always JSON, never raise (`TalariaError.to_json()` plus a catch-all). Missing ctx returns the previous stub JSON rather than raising. Extra kwargs (`extra=True`) are accepted. Import of `talaria.tools` and `register(ctx)` open no sockets. `bind_ctx` is not called from `register()` — allowed; tests pass `ctx=` (or `bind_ctx` in one test). Write tools stay stubs.
- SECURITY: Met. Tool JSON, goldens, and 401 error payloads never contain the bearer. `_probe_env` copies only `label`/`environmentId` from the descriptor; condensed list/thread copy named T3 fields only. 401 maps to `NotAuthenticated` and drops the body (a body that itself contains the token does not leak). `runtime_mode` in `T3_PROMPT_SCHEMA` still defaults to `approval-required` and tells the model not to use `full-access` unless asked; read handlers do not dispatch `runtimeMode`.
- TESTS: Met. AC1 is `tests/test_read_tools.py` `test_t3_list_golden_includes_worktree_latest_turn_pending` against `tests/fixtures/shell_snapshot.json` / `t3_list.golden.json`. AC2 is `test_t3_thread_oversized_sets_truncated_and_keeps_latest` (`truncated is True`, latest turn kept, `len(raw) <= 32768`). Also: environments golden, agent-output + `page.beforeCursor` golden, default and explicit `turnLimit`, no-secret and 401 JSON paths, discovered `mode=t3connect`, unknown-field parse, kwargs/`bind_ctx`, factory boom does not raise, no `sleep`, `httpx.MockTransport` only (`https://t3.example.test`).

Test seams are `bind_ctx` and `set_client_factory` (MockTransport into `T3EnvClient(client=)`). No parser framework, no AuthStrategy, no extra modules beyond the item's files.
