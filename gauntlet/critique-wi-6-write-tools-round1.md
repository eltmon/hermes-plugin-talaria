## Criteria
- CORRECTNESS: Met. `thread.turn.start` from `t3_prompt` is field-for-field the PRD transcription / t3code `ClientThreadTurnStartCommand` (`packages/contracts/src/orchestration.ts`): `type`, `commandId` (uuid4), `threadId`, `message.{messageId, role: "user", text, attachments}`, optional `modelSelection.{instanceId, model}`, `runtimeMode`, `interactionMode`, `createdAt` (ISO-8601 `…sssZ`). Optional upstream keys (`titleSeed`, `bootstrap`, `sourceProposedPlan`) are omitted. `model_selection` is optional on `t3_prompt` (WI-6 + `Schema.optional(ModelSelection)`); when present, `instance_id`/`instanceId` maps to wire `instanceId`. Omitted `runtime_mode` always sends `approval-required` (never T3's `ThreadTurnStartCommand` decode-default `full-access`); `attachments` is always `[]`, never omitted (client schema requires the array). `thread.create` from `t3_new_thread` sends client-generated uuid4 `threadId`, required `modelSelection`, `runtimeMode`/`interactionMode` (default `approval-required` / `default`), `branch: null`, `worktreePath: null`. `t3_interrupt` / `t3_respond` match `ThreadTurnInterruptCommand` (no `turnId`), `ThreadApprovalRespondCommand` (`accept|acceptForSession|acceptAlways|decline|cancel`), and `ThreadUserInputRespondCommand` (`answers` record). Unknown modes/kinds/decisions are rejected before POST.
- CONTRACT: Met. Write handlers are `(args: dict, **kwargs) -> str`, always JSON, never raise (`TalariaError.to_json()` plus `_unexpected`). Extra kwargs (`extra=True`) accepted. Missing ctx (or scaffold FakeCtx without `get_config`) still returns the WI-1 stub JSON. `t3_wait` stays a stub. Import of `talaria.commands` / `talaria.tools` and `register(ctx)` open no sockets.
- SECURITY: Met. Dispatched command JSON has no bearer. Tool success JSON is `environment` / `type` / `commandId` / `threadId` / optional `messageId` plus the dispatch body (`sequence`); 401 maps to `NotAuthenticated` and drops the body (a 401 JSON that itself contains the token does not leak). Tests use the short fake `tok-test` only, and only as the Authorization header plus that 401-body check. `DEFAULT_RUNTIME_MODE` is `approval-required`; `full-access` is sent only as the exact literal (strip allowed, aliases like `full_access` / `FULL-ACCESS` / `danger-full-access` rejected). Schema copy tells the model not to use `full-access` unless asked.
- TESTS: Met. AC1 is `tests/test_write_tools.py` `test_prompt_turn_start_matches_prd_shape` — MockTransport captures `POST /api/orchestration/dispatch` and equality-compares the body to the PRD dict. AC2 is `test_prompt_omitted_runtime_mode_is_approval_required_attachments_empty` (`runtimeMode == "approval-required" != "full-access"`, `attachments == []`, no `modelSelection`) plus the same full-dict fixture. Also: `thread.create` / interrupt / both `t3_respond` kinds as fixture dicts, unknown mode/kind/decision not dispatched (malformed args), missing auth, 401 JSON-not-raise without token leak, factory boom does not raise, kwargs/`bind_ctx`, no `sleep`, `httpx.MockTransport` only (`https://t3.example.test`).
- SIMPLICITY: Met. `talaria/commands.py` is pure dict builders + small literal helpers — not a command bus, not HTTP. Handlers are the spotify `plugins/spotify/tools.py` shape: per-tool `try/except`, JSON string, `**kwargs`, shared `_dispatch_command` POST. No pydantic models, no registry, no extra modules beyond the item's files.
