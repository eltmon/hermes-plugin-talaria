Independent probe: host-grant-only → `injection_granted` False; settings-grant-only → True; denied JSON hint contains the host path and not `settings`. 2. **`kind=thread` never emits turn-settled when the turn actually finishes.** [`talaria/watch.py`](/home/eltmon/Projects/hermes-plugin-talaria/talaria/watch.py) `_apply_thread_event` fires `turn-settled` / `turnState=completed` on `type == "thread.settled"`.
