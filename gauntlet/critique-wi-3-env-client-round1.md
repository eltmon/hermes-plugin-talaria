# WI-3 env-client — round 1
Verdict: PASS

## Criteria
- CORRECTNESS: Met. `T3EnvClient` implements `descriptor`, `shell`, `thread(thread_id, turn_limit, before_cursor)`, `dispatch`, `ws_ticket`, `exchange_pairing`, `exchange_dpop`. Module-level `exchange_pairing(base_url, subject_token)` and `exchange_dpop(base_url, credential, dpop_signer)` match the PRD signatures. Paths are `GET /.well-known/t3/environment`, `GET /api/orchestration/shell`, `GET /api/orchestration/threads/:id` with camelCase `turnLimit`/`beforeCursor`, `POST /api/orchestration/dispatch`, `POST /api/auth/websocket-ticket`, `POST /oauth/token`. Pairing form is RFC 8693 urlencoded with exact `subject_token_type=urn:t3:params:oauth:token-type:environment-bootstrap` plus PRD `grant_type`, `requested_token_type`, `scope` (AuthStandardClientScopes), `client_label=hermes-talaria`, `subject_token`. DPoP exchange uses the same form plus a `dpop` header (T3 `AuthTokenExchangeRequest` / `exchangeRemoteDpopAccessToken`). 401 → `NotAuthenticated`; other non-2xx → `T3ApiError(status, body)`. `_parse` returns `response.json()` with no schema drop, so unknown fields survive (NFR-5). Wire names checked against t3code `packages/contracts/src/auth.ts` (`AuthTokenExchangeRequest`) and `packages/client-runtime/src/authorization/remote.ts`.
- CONTRACT: Met. `import talaria.t3_env` and `register(ctx)` open no sockets (project `socket_guard` plus a live constructor-deny probe). `get_client` is `@_lazy_singleton` (hermes `plugins.plugin_utils.lazy_singleton` when present; double-checked-lock copy otherwise — not `global x` + `is None`). The `httpx.Client(timeout=30.0)` is built on first use, one process-wide client. Auth is `headers_fn: Callable[[], Mapping[str, str]]` merged per request; descriptor/token exchanges set `auth=False`. Tool handlers were not touched and still return stub JSON. Diff is only `talaria/t3_env.py`, `tests/test_t3_env.py`, and `pyproject.toml` (`httpx` added).
- SECURITY: Met. Client code never interpolates the bearer/subject token into exceptions. 401 mapping discards the response body. Tests use short fakes (`tok-test`, `proof-test`, `https://t3.example.test`). No token in repo/config/state.
- TESTS: Met. `tests/test_t3_env.py` drives `httpx.MockTransport` (no live servers, no `sleep`). AC1: success test per method plus parametrized 401 → `NotAuthenticated` for all seven endpoints. AC2: pairing form asserts exact `subject_token_type` and the rest of the PRD fields, `application/x-www-form-urlencoded`, no `Authorization`. Extra coverage: per-request `headers_fn`, camelCase query omit-if-None, DPoP proof `(POST, url)`, unknown-field passthrough, 403 stays `T3ApiError`, trailing-slash origin join. No clock needed (no delays).
- SIMPLICITY: Met. One class + `_request` + headers callable, same shape as hermes `plugins/spotify/client.py` without Spotify's per-call `httpx.request` (PRD requires a reused Client) and without an AuthStrategy hierarchy. Token-exchange form is one dict helper shared by pairing and DPoP. URL join replaces pathname like t3code `environmentEndpointUrl`.
